# Rohit Gund Portfolio

Modern portfolio website built with Next.js App Router and deployed-ready for Vercel.

## Tech Stack

- Next.js
- React
- TypeScript
- CSS
- Vercel-ready static prerendered routes

## Local Development

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:3000`.

## Scripts

```bash
npm run dev
npm run lint
npm run build
npm run start
```

## Routes

- `/`
- `/projects`
- `/social-media`
- `/contact`
